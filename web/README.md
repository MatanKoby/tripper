# tripper web

Vite + React (TypeScript) frontend for tripper. Deployed on Vercel with the
project **Root Directory** set to `web/`.

- `npm install` then `npm run dev` to run locally.
- `npm run build` outputs `dist/`.

M1 is an unstyled wireframe (see `spec/ui.md`). Auth, the trip-input form, and
the Firestore job flow arrive in the full Batch 7.
